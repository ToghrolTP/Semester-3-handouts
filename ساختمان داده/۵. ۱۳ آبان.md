## تحلیل پیچیدگی الگوریتم‌ها

### مقدمه

در ارزیابی یک الگوریتم، دو فاکتور مهم مورد توجه قرار می‌گیرد:

1. **فضای حافظه** (Space Complexity)
2. **زمان** (Time Complexity)

در این بخش، تمرکز اصلی بر روی **پیچیدگی زمانی** است.

### مفاهیم اساسی پیچیدگی زمانی

یک الگوریتم زمانی کارآمد است که از لحاظ زمان اجرا بهینه باشد. برای تحلیل پیچیدگی زمانی:

- اگر `n` ورودی داشته باشیم → `T(n)` زمان اجرا خواهیم داشت
- از رابطه `T(n)` می‌توانیم `O(n)` (نماد Big-O) را به دست آوریم

#### نکته مهم

برای حل مسائل مربوط به پیچیدگی زمانی، **تعریف متغیر**، **شروع** و **پایان** برنامه هیچ مقداری در محاسبات در نظر گرفته نمی‌شود.

---

## مثال‌های محاسبه پیچیدگی زمانی

### مثال ۱: محاسبه مجموع آرایه

```c
Float sum (Float List[], int n) {     // -----> 0
    Float s = 0;                       // -----> 1
    int i;                             // -----> 0
    For (i = 0; i < n; i++)           // -----> n - 0 + 1 = n + 1
        s = s + list[i];              // -----> n
    return s;                          // -----> 1
}                                      // -----> 0
```

**محاسبه:**

```
مجموع = 1 + (n + 1) + n + 1 = 2n + 3
نتیجه: O(n)
```

---

### مثال ۲: حلقه‌های تو در تو

```
For (i = 1 to n do)
    For (j = 1 to i do)
        For (k = 1 to n do)
            n := n + 1;
```

**تحلیل:**

- حلقه اول: `n` بار
- حلقه دوم: `1 + 2 + 3 + ... + n` بار
- حلقه سوم: `n` بار

**گزینه‌های ارائه شده:**

1. O(n²)
2. O(n³)
3. O(2ⁿ)
4. O(n² log₂ n)

**پاسخ:** گزینه ۲ - O(n³)

---

### مثال ۳: تابع بازگشتی (Recursive Function)

```pascal
Function F(n: integer): integer; {
    if (n < 3) then 
        f := n;
    else
        f := f(n-1) + f(n-2) + f(n-3)
    end
}
```

**سؤال:** خروجی تابع برای `n = 4` چقدر است؟

**تحلیل:** این یک تابع بازگشتی شبیه به دنباله فیبوناچی است که پیچیدگی زمانی نمایی دارد.

## جدول مراتب پیچیدگی زمانی

اندازه یا مرتبه پیچیدگی زمانی در ساختمان داده‌ها شامل حالت‌های مختلفی است که بر اساس میزان مصرف زمان برای ورودی‌های متفاوت مقایسه می‌شوند:

| مرتبه پیچیدگی    | نماد       | مثال کاربردی                  | سرعت افزایش  |
| ---------------- | ---------- | ----------------------------- | ------------ |
| **ثابت**         | O(1)       | دسترسی مستقیم به عنصر آرایه   | کمترین رشد   |
| **لگاریتمی**     | O(log n)   | جستجوی دودویی (Binary Search) | خیلی کم      |
| **خطی**          | O(n)       | جستجوی خطی (Linear Search)    | خطی          |
| **خطی-لگاریتمی** | O(n log n) | مرتب‌سازی ادغامی (Merge Sort) | کمی بیشتر    |
| **درجه دوم**     | O(n²)      | مرتب‌سازی حبابی (Bubble Sort) | رشد سریع     |
| **نمایی**        | O(2ⁿ)      | حل کامل مسئله کوله‌پشتی       | بسیار زیاد   |
| **فاکتوریل**     | O(n!)      | تولید همه جایگشت‌ها           | شدیدترین رشد |

### مقایسه کارایی

از بهترین به بدترین:

```
O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)
```

## فصل ۲: صف (Queue)

### تعریف

صف یک **لیست مرتب** است که در آن:

- **عمل اضافه کردن (Enqueue)**: از یک طرف به نام **Rear** (انتهای صف)
- **عمل حذف/خواندن (Dequeue)**: از طرف دیگر به نام **Front** (ابتدای صف)

### ویژگی اصلی: FIFO

صف به عنوان **FIFO** (First In, First Out) شناخته می‌شود:

- **اولین عنصر وارد شده، اول خارج می‌شود**

---

### پیاده‌سازی صف با آرایه

#### تعریف متغیرها

```
q: Array[1...n] of items;
```

#### اشاره‌گرها (Pointers)

برای کار با صف به **دو اشاره‌گر** نیاز داریم:

- **Front**: اشاره به ابتدای صف (عنصر قبل از عنصر اول)
- **Rear**: اشاره به انتهای صف (آخرین عنصر)

#### مقادیر اولیه و شرایط

```
Front = Rear = 0              → مقدار اولیه (صف خالی)
Front, Rear ∈ [0...n]         → دامنه تغییرات
```

#### شرایط صف

| شرط             | فرمول          | توضیح                  |
| --------------- | -------------- | ---------------------- |
| **صف خالی است** | `Front = Rear` | هیچ عنصری در صف نیست   |
| **صف پر است**   | `Rear = n`     | تمام ظرفیت استفاده شده |

---

### عملیات اصلی صف

1. **Enqueue (اضافه کردن)**
    
    - عنصر جدید به انتهای صف (Rear) اضافه می‌شود
    - `Rear` یک واحد افزایش می‌یابد
2. **Dequeue (حذف کردن)**
    
    - عنصر از ابتدای صف (Front) حذف می‌شود
    - `Front` یک واحد افزایش می‌یابد
3. **IsEmpty (بررسی خالی بودن)**
    
    - بررسی شرط: `Front = Rear`
4. **IsFull (بررسی پر بودن)**
    
    - بررسی شرط: `Rear = n`

---

## نکات کلیدی

### پیچیدگی زمانی

- همیشه به دنبال ساده‌سازی فرمول نهایی باشید
- ضرایب ثابت و جملات کوچک‌تر را نادیده بگیرید
- فقط بالاترین مرتبه را در نظر بگیرید

### صف

- از صف برای مدیریت وظایف به ترتیب زمانی استفاده می‌شود
- کاربردها: سیستم‌های چاپ، مدیریت فرآیندها، الگوریتم‌های BFS
