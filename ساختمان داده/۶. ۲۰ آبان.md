## پشته (Stack)

### تعریف
پشته لیستی مرتب است که عملیات اضافه و حذف کردن از یک طرف (بالا) انجام می‌گیرد.  
- **LIFO** (Last In, First Out): آخرین عنصر وارد شده، اولین عنصری است که خارج می‌شود.  
- **نکته**: FIFO مربوط به صف است، نه پشته.

### کاربردها
یکی از کاربردهای پشته، ذخیره آدرس‌های بازگشتی و ساخت متغیرهای محلی در صدا زدن توابع است.

### نمایش پشته
پشته را می‌توان با یک آرایه یک‌بعدی به طول n نشان داد، که عناصر از 1 تا n شماره‌گذاری شده‌اند.  
- متغیر **Top**: به عنصر بالایی اشاره می‌کند و مقدار آن از 0 تا n است.  
- مقدار اولیه Top: 0  

**دیاگرام ساده پشته (به صورت متنی):**

```
+----------+
| Element  |  <- Top (بالا)
+----------+
| Element  |
+----------+
| ...      |
+----------+
| Element  |  <- Bottom (پایین)
+----------+
```

- **نوع داده**: `stack: Array [1...n] of items`  
- **دامنه Top**: 1 تا n (هنگام پر بودن)  
- **مقدار اولیه Top**: 0  
- **شرط خالی بودن**: if Top = 0  
- **شرط پر بودن**: if Top = n (تصحیح احتمالی از 1 به n بر اساس کد)

### زیربرنامه اضافه کردن به پشته (Push)
```pascal
procedure push(k: item) {
  if Top = n then  // شرط پر بودن
    stack full
  else {  // قرار دادن در بالای استک
    Top = Top + 1
    stack[Top] = k
  }
}
```

### زیربرنامه حذف از پشته (Pop)
```pascal
procedure pop(k: item) {
  if Top = 0 then  // شرط خالی بودن
    stack empty
  else {
    k = stack[Top]
    Top = Top - 1
  }
}
```

## صف‌های حلقوی (Circular Queue)

### نکته
صف‌های معمولی یک‌بار قابل استفاده هستند، یعنی اگر به انتهای صف برسیم، دیگر نمی‌توان چیزی ذخیره کرد. برای رفع این مشکل از صف‌های حلقوی استفاده می‌کنیم.

### شرط‌ها
- **مقدار اولیه**: Front = Rear  
- **شرط خالی بودن**: if Front == Rear  
- **به‌روزرسانی Rear**: Rear = (Rear + 1) mod n  // تصحیح احتمالی از Rear1 به Rear + 1
