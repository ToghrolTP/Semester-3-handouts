# جزوه ساختمان داده - فصل دوم: توابع بازگشتی (Recursion)

---

## مفاهیم پایه توابع بازگشتی

### تعریف:

**تابع بازگشتی:** تابعی که خودش را با آرگومان‌های کوچک‌تر فراخوانی می‌کند.

---

## دو ویژگی مهم توابع بازگشتی ⭐

### 1. فراخوانی خود با آرگومان‌های کمتر

تابع خودش را با مقادیر کوچک‌تر صدا می‌زند.

### 2. شرط پایان (Base Case)

یک شرط برای اتمام فراخوانی‌های بازگشتی وجود دارد.

---

## مثال 1: محاسبه فاکتوریل (Factorial)

### تعریف ریاضی:

```
n! = n × (n-1) × (n-2) × ... × 2 × 1

مثال:
5! = 5 × 4 × 3 × 2 × 1 = 120
3! = 3 × 2 × 1 = 6
```

---

### کد بازگشتی (Pascal):

```pascal
var n: integer;

Function Fact(n: integer): integer;
begin
    if n <= 1 then 
        Fact := 1                    // Base case
    else 
        Fact := n * Fact(n-1);       // Recursive call
end;

begin
    Readln(n);
    Writeln(Fact(n));
end.
```

---

### ردیابی اجرا (Trace) برای `n = 4`:

```
Fact(4) 
├─> 4 × Fact(3)
    ├─> 3 × Fact(2)
        ├─> 2 × Fact(1)
            └─> 1           // Base case

برگشت به عقب:
Fact(1) = 1
Fact(2) = 2 × 1 = 2
Fact(3) = 3 × 2 = 6
Fact(4) = 4 × 6 = 24
```

**نتیجه:** `Fact(4) = 24`

---

### جدول فراخوانی‌ها:

|n|فراخوانی|نتیجه|
|---|---|---|
|1|`Fact(1)`|`1`|
|2|`Fact(2) = 2 × Fact(1)`|`2 × 1 = 2`|
|3|`Fact(3) = 3 × Fact(2)`|`3 × 2 = 6`|
|4|`Fact(4) = 4 × Fact(3)`|`4 × 6 = 24`|

---

## مثال 2: تابع T(n)

### کد:

```pascal
Function T(n: integer): integer;
begin
    if n = 1 then 
        T := 0                       // Base case
    else
        T := n * T(n-1) + n²;       // Recursive formula
end;
```

---

### محاسبه برای `n = 4`:

```
T(1) = 0                             // Base case

T(2) = 2 × T(1) + 2²
     = 2 × 0 + 4
     = 4

T(3) = 3 × T(2) + 3²
     = 3 × 4 + 9
     = 12 + 9
     = 21

T(4) = 4 × T(3) + 4²
     = 4 × 21 + 16
     = 84 + 16
     = 100
```

✅ **پاسخ:** `T(4) = 100`

---

### جدول محاسبات:

|n|محاسبه|نتیجه|
|---|---|---|
|1|`T(1)`|`0`|
|2|`2 × 0 + 4`|`4`|
|3|`3 × 4 + 9`|`21`|
|4|`4 × 21 + 16`|`100`|

## مثال 3: تابع فیبوناچی (Fibonacci)

### کد:

```pascal
Function f(y: integer): integer;
begin
    if y <= 0 then 
        f := 2                       // Base case
    else 
        f := f(y-1) + f(y-2);       // Recursive formula
end;
```

---

### محاسبه برای `y = 2`:

```
f(0) = 2                             // Base case
f(-1) = 2                            // Base case

f(1) = f(0) + f(-1)
     = 2 + 2
     = 4

f(2) = f(1) + f(0)
     = 4 + 2
     = 6
```

✅ **پاسخ:** `f(2) = 6`

---

### درخت فراخوانی‌ها:

```
           f(2)
          /    \
       f(1)    f(0)=2
       /  \
    f(0)  f(-1)
     2      2

محاسبه:
f(1) = 2 + 2 = 4
f(2) = 4 + 2 = 6
```

---

### جدول محاسبات:

|y|محاسبه|نتیجه|
|---|---|---|
|≤0|`Base case`|`2`|
|1|`f(0) + f(-1) = 2 + 2`|`4`|
|2|`f(1) + f(0) = 4 + 2`|`6`|

---

## مثال 4: تابع ترکیبی (Combination) - `F(3, 6)`

### کد (C):

```c
int F(int m, int n) {
    if (m == 1 || n == 0 || m == n)
        return 1;                    // Base cases
    else 
        return F(m-1, n) + F(m-1, n-1);
}
```

---

### محاسبه برای `F(3, 6)`:

```
F(3, 6)
├─> F(2, 6) + F(2, 5)
    │
    ├─> F(2, 6)
    │   ├─> F(1, 6) + F(1, 5)
    │   └─> 1 + 1 = 2
    │
    └─> F(2, 5)
        ├─> F(1, 5) + F(1, 4)
        └─> 1 + 1 = 2

F(3, 6) = 2 + 2 = 4
```

---

### محاسبه دقیق‌تر:

#### مرحله 1: `F(2, 6)`

```
F(2, 6) = F(1, 6) + F(1, 5)
        = 1 + 1                      // Base case: m=1
        = 2
```

#### مرحله 2: `F(2, 5)`

```
F(2, 5) = F(1, 5) + F(1, 4)
        = 1 + 1                      // Base case: m=1
        = 2
```

#### نتیجه نهایی:

```
F(3, 6) = F(2, 6) + F(2, 5)
        = 2 + 2
        = 4
```

✅ **پاسخ:** `F(3, 6) = 4`

---

### شرایط پایه (Base Cases):

این تابع معادل **ترکیب** در ریاضیات است: C(m, n) = n!/(m!(n-m)!)

**شرایط پایه:**

1. `m = 1`: انتخاب یک عنصر → `1`
2. `n = 0`: هیچ عنصری برای انتخاب نیست → `1`
3. `m = n`: انتخاب همه عناصر → `1`

---

## جدول مقایسه مثال‌ها

|مثال|تابع|Base Case|فرمول بازگشتی|
|---|---|---|---|
|فاکتوریل|`Fact(n)`|`n ≤ 1 → 1`|`n × Fact(n-1)`|
|تابع T|`T(n)`|`n = 1 → 0`|`n × T(n-1) + n²`|
|فیبوناچی|`f(y)`|`y ≤ 0 → 2`|`f(y-1) + f(y-2)`|
|ترکیب|`F(m,n)`|`m=1 یا n=0 یا m=n → 1`|`F(m-1,n) + F(m-1,n-1)`|

---

## نکات مهم برای حل مسائل بازگشتی ⭐

### 1. شناسایی Base Case

ابتدا شرط پایان را پیدا کنید.

### 2. ردیابی از پایین به بالا

از Base Case شروع کرده و به سمت ورودی اصلی بروید.

### 3. رسم درخت فراخوانی‌ها

برای توابع پیچیده (مثل فیبوناچی) درخت بکشید.

### 4. جدول محاسبات

برای مقادیر کوچک، جدول بسازید.

## الگوی کلی تابع بازگشتی

```
Function Recursive(parameter):
    if (base_condition):           // شرط پایان
        return base_value
    else:
        return operation(Recursive(smaller_parameter))
```

## مزایا و معایب توابع بازگشتی

### مزایا:

- ✅ کد ساده‌تر و خواناتر
- ✅ راه‌حل طبیعی برای مسائل بازگشتی
- ✅ کوتاه‌تر از حلقه‌ها

### معایب:

- ❌ مصرف حافظه بیشتر (Stack Overflow)
- ❌ ممکن است کندتر از حلقه باشد
- ❌ فراخوانی‌های اضافی (overhead)
