# جزوه مدار منطقی - کدگذاری اعداد (Number Codes)

---

## انواع کدهای BCD (Binary Coded Decimal)

**BCD:** روشی برای نمایش اعداد دهدهی با استفاده از کدهای دودویی

---

## 1. کد 8421 (Standard BCD)

### ویژگی‌ها:

- **رایج‌ترین کد BCD**
- وزن بیت‌ها از چپ به راست: **8, 4, 2, 1**
- نمایش مستقیم دودویی

---

### جدول کد 8421:

| عدد دهدهی | کد 8421 | محاسبه                    |
| --------- | ------- | ------------------------- |
| 0         | 0000    | 0×8 + 0×4 + 0×2 + 0×1 = 0 |
| 1         | 0001    | 0×8 + 0×4 + 0×2 + 1×1 = 1 |
| 2         | 0010    | 0×8 + 0×4 + 1×2 + 0×1 = 2 |
| 3         | 0011    | 0×8 + 0×4 + 1×2 + 1×1 = 3 |
| 4         | 0100    | 0×8 + 1×4 + 0×2 + 0×1 = 4 |
| 5         | 0101    | 0×8 + 1×4 + 0×2 + 1×1 = 5 |
| 6         | 0110    | 0×8 + 1×4 + 1×2 + 0×1 = 6 |
| 7         | 0111    | 0×8 + 1×4 + 1×2 + 1×1 = 7 |
| 8         | 1000    | 1×8 + 0×4 + 0×2 + 0×1 = 8 |
| 9         | 1001    | 1×8 + 0×4 + 0×2 + 1×1 = 9 |

---

## 2. کد 4221

### ویژگی‌ها:

- وزن بیت‌ها: **4, 2, 2, 1**
- **Self-complementing code** (خود-مکمل)
- مکمل 9 با معکوس کردن بیت‌ها به دست می‌آید

---

### جدول کد 4221:

|عدد دهدهی|کد 4221|محاسبه|
|---|---|---|
|0|0000|0×4 + 0×2 + 0×2 + 0×1 = 0|
|1|0001|0×4 + 0×2 + 0×2 + 1×1 = 1|
|2|0010|0×4 + 0×2 + 1×2 + 0×1 = 2|
|3|0011|0×4 + 0×2 + 1×2 + 1×1 = 3|
|4|1000|1×4 + 0×2 + 0×2 + 0×1 = 4|
|5|1001|1×4 + 0×2 + 0×2 + 1×1 = 5|
|6|1100|1×4 + 1×2 + 0×2 + 0×1 = 6|
|7|1101|1×4 + 1×2 + 0×2 + 1×1 = 7|
|8|1110|1×4 + 1×2 + 1×2 + 0×1 = 8|
|9|1111|1×4 + 1×2 + 1×2 + 1×1 = 9|

---

### ویژگی Self-Complementing:

```
مکمل 9 عدد = معکوس بیت‌ها

مثال:
عدد 3 → 0011
مکمل 9 (یعنی 6) → 1100 ✓

عدد 7 → 1101
مکمل 9 (یعنی 2) → 0010 ✓
```

---

## 3. کد 3-افزا (Excess-3)

### تعریف:

**کد 3-افزا:** ابتدا به عدد دهدهی **3 واحد اضافه** می‌کنیم، سپس معادل **کد 8421** آن را می‌نویسیم.

```
Excess-3 = BCD(8421) + 3
```

---

### جدول کد 3-افزا:

|عدد دهدهی|+3|کد 3-افزا|توضیح|
|---|---|---|---|
|0|0+3=3|0011|BCD(3)|
|1|1+3=4|0100|BCD(4)|
|2|2+3=5|0101|BCD(5)|
|3|3+3=6|0110|BCD(6)|
|4|4+3=7|0111|BCD(7)|
|5|5+3=8|1000|BCD(8)|
|6|6+3=9|1001|BCD(9)|
|7|7+3=10|1010|BCD(10)|
|8|8+3=11|1011|BCD(11)|
|9|9+3=12|1100|BCD(12)|

---

### ویژگی‌های کد 3-افزا:

1. **Self-complementing:** مانند کد 4221
2. **بدون صفر:** هیچ رقمی به صورت 0000 نمایش داده نمی‌شود
3. **کاربرد:** در مدارهای جمع و تفریق BCD

---

## مثال: تبدیل عدد 836 به کد 3-افزا

### روش حل:

**مرحله 1:** به هر رقم 3 واحد اضافه کنید

```
  836
+ 333
─────
 1169
```

> **نکته:** رقم هزارگان (1) را نادیده می‌گیریم زیرا از 9 بزرگ‌تر است.

---

**مرحله 2:** هر رقم را به کد 8421 تبدیل کنید

```
1 → (نادیده گرفته می‌شود)
1 → 0001
6 → 0110
9 → 1001
```

---

**نتیجه نهایی:**

```
836 (دهدهی) = 0001 0110 1001 (کد 3-افزا)
                 ↓    ↓    ↓
                 1    6    9
```

یا می‌توان به صورت **B169** نوشت که B نشان‌دهنده BCD است.

---

### روش دیگر (رقم به رقم):

```
رقم 8:
8 + 3 = 11 (B)
11 در دهدهی = 1011 در دودویی

رقم 3:
3 + 3 = 6
6 در دهدهی = 0110 در دودویی

رقم 6:
6 + 3 = 9
9 در دهدهی = 1001 در دودویی

نتیجه: 1011 0110 1001
```

✅ **پاسخ نهایی:** `836₁₀ = (1011 0110 1001)Excess-3` یا `B169`

## کاربردها

### کد 8421:

- **رایج‌ترین** برای نمایش BCD
- ساده و مستقیم
- استفاده در نمایشگرهای هفت‌بخشی

### کد 4221:

- محاسبه **مکمل 9** آسان
- عملیات جمع و تفریق BCD

### کد 3-افزا:

- **تشخیص خطا** آسان‌تر
- عملیات جمع و تفریق بدون نیاز به تصحیح اضافی
- استفاده در مدارهای قدیمی

---

## نکات مهم ⭐

1. **همه کدها 4 بیتی هستند** برای نمایش ارقام 0-9
    
2. **کدهای Self-Complementing:**
    
    - 4221 و 3-افزا
    - مکمل 9 = معکوس بیت‌ها
3. **محدودیت BCD:**
    
    - فقط 10 حالت از 16 حالت ممکن استفاده می‌شود
    - 6 کد غیرمجاز: 1010-1111 (در 8421)
4. **تبدیل 3-افزا:**
    
    - هر رقم جداگانه: رقم + 3 → BCD
    - توجه به carry در جمع

---

## تمرین‌های پیشنهادی 📝

1. عدد `547` را به کد 3-افزا تبدیل کنید.
2. کد 3-افزا `0111 1011 1001` را به دهدهی تبدیل کنید.
3. عدد `29` را در کدهای 8421، 4221 و 3-افزا بنویسید.
4. چرا کدهای 4221 و 3-افزا Self-Complementing هستند؟

## فرمول‌های کلیدی

### تبدیل به کد 3-افزا:

```
برای هر رقم d:
Excess-3(d) = BCD(d + 3)
```

### تبدیل از کد 3-افزا:

```
برای هر رقم کدشده x:
d = BCD_to_Decimal(x) - 3
```

### مکمل 9 (در کدهای Self-Complementing):

```
Complement(x) = NOT(x)
```
